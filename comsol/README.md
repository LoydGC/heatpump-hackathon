# COMSOL models

Put `.mph` files here (building envelope, heat pump cycle, etc.).

- Save with **File > Compact History** and **without solution data** (or clear meshes/solutions) before committing, so files stay small. Anything over ~50 MB: share via Drive and link it here.
- Export results the Python pipeline needs (hourly load profile, capacity/COP vs. temperature tables) as CSV to `data/processed/`, and note the export settings below.
- One owner per `.mph` file at a time: binary files can't be merged. Say in the team chat before editing.
